# Pattern spec — contest-loop

Read-only empty shell. Not a runtime track, not a Promotion key, not
orchestration code. The Team Coordinator does not switch tracks because this
file exists.

## Who plays

- Contest-shaped stages on the thin Team: propose a Candidate, measure
  it, iterate.
- Team Coordinator, one default Branch, and the existing Evaluator
  boundary. No Antigravity standing roster.
- Verification Roles stay off unless callbacks are provided.

## Advance conditions

- Evidence and Evaluator observations decide whether to continue,
  repair, or stop at the Mission layer.
- Local Promotion still requires the existing evidence gates. This
  Pattern does not authorize External Submission.
- Hang / T48 three-state is unchanged and is not owned here.

A standing verification roster is not an advance condition. Contest
stage names, Elite labels, and Role lists are not Promotion keys.
