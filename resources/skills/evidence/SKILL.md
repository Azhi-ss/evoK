# Evidence

Help keep **Evidence** as a traceable observation or **Artifact** — including the conditions under which it was obtained. A Finding is drawn from Evidence within stated scope. A Claim or opinion is not Evidence.

This skill is instruction only. Loading L0 or L1 is not authorization to start, continue, or submit. External Submission stays frozen. `/start`, `/research continue`, and submit stay on Mission gates. Chat is not authority. Do not dispatch work from this text. This skill does not relax Admission, Budget, hang, T48, or Promotion predicates.

Authoring language of this skill is English. **Respond in the user's language** unless the user asks otherwise. Keep code identifiers, tool names, file paths, and metric names exactly as written.

## Lineage

Record each item so a later Auditor can replay it:

- **what** — the observation or Artifact identity
- **conditions** — environment, Split Contract, and evaluation contract in force
- **support or contradict** — which Finding the item bears on
- **ledger ref** — content-addressed pointer a later Task can read
- **Negative Evidence** — failure or inconclusion under recorded circumstances; it is still Evidence

The **File Blueprint** (GOAL, RULES, experiment log, SCOREBOARD) is Evidence. Those files do not score, promote, or authorize Stop by themselves.

## Validity, not a bypass

**Experiment Validity** asks whether the Experiment produced usable gate evidence.

- Effectiveness on official samples is not optimality.
- Inconclusive is not pass.
- A missing **protected holdout** still refuses **Admission**. Official samples plus an adversarial-labeled subset are not enough.
- Hang is an explicit hang point, not a silent pass. T48 mapping still applies. This skill does not change those predicates.

Do not treat this skill as Admission, Promotion, Budget pass, or a relaxation of `#40` / true submit.

## Handoff

When the lineage is sound, present the Evidence refs for review. Leave start / continue / submit to an explicit later Mission action. Missing evaluation, missing authorization, or a Budget refuse still refuse — this skill does not relax those gates.
