## Demo「插件可卸」

最短可复现路径（不需要模型、不启动 TUI）：

```bash
bun test src/search/sea-plugin.test.ts -t "mount then unmount"
bun test src/search/sea-plugin.test.ts -t "MCTS mount is expressible"
```

期望：

1. 未挂插件时 `defaultSelection().id === "fixed_uct"`，worked example 选父本为 `b`。
2. `mount(createMctsSeaPlugin())` 后默认路径仍是 `fixed_uct`；`optInSelection()` 拒绝（MCTS 选点数学未开）。
3. `unmount()` 后 `mounted()` 为空，默认选点与从未挂载时相同。
4. env / `#40` **不会**静默挂上 Progressive 或 MCTS。

对照 Progressive 显式 opt-in（仍不是产品默认）：

```bash
bun test src/search/sea-plugin.test.ts -t "explicit Progressive plugin opt-in"
```

## Demo「版本统计隔离」

```bash
bun test src/search/method-version-stats.test.ts -t "old-version visits are history"
bun test src/search/method-version-stats.test.ts -t "adoptAsAuthority refuses"
bun test src/search/method-version-stats.test.ts -t "after a switch uses only the new version"
```

期望：

1. `switchTo("method@1")` 记录 `champ` visits=10 后，`authority()` 只有该行。
2. `switchTo("method@2")` 后 `authority()` 为空；`history("method@1")` 仍是 visits=10。
3. 新版本记录 `challenger` 后，`adoptAsAuthority("method@1")` 为 `refuse` / `version_mismatch`，权威仍只有 `challenger`。
4. `toParentCandidates()` 交给默认 `fixed_uct` 时，切换后选中 `challenger`，不会沿用 v1 的 `a`/`b`/`c` 访问数。
