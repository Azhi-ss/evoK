## 什么破了 / 怎么修

| 0.83→0.86 break | evoK 受不受影响 | 修法 |
|---|---|---|
| `user_bash` fail-closed：handler 抛错或返回非法 defined 结果会中止，**不再**落到后续 handler / 本地执行。合法返回只有 `undefined`（继续）或 `{ operations }` / `{ result }`（停止） | **是。** 原先 Run sandbox 扩展只拦 `tool_call`，`!` / RPC bash 会绕过 | 新增 `resolveUserBash`：无 `allowBash` 或命令违规一律返回 defined `{ result }`（exitCode 1），**不抛**。sandbox 扩展注册 `user_bash`。`powershell` / `user_bash` 视作 shell 工具，与 bash 同闸 |
| `TranscriptContext`：自定义 provider stream 输入从 `Context` 改为规范化 transcript；须用 `getCurrentSystemPrompt()` / `getCurrentTools()` | **否。** evoK 没有手写 custom streaming provider；测试用 `fauxProvider` 来自更新后的 `@earendil-works/pi-ai/compat` | 无代码改动。勿在本票引入自定义 provider |
| `ToolCall.arguments` / `ToolResultMessage.details` 限 JSON-compatible；`ToolResultMessage` 变条件类型 | **检查过。** intake `defineTool` 仍返回 `{ content, details: undefined }` | typecheck 绿，未改合同 |
| `session_compact_failed`（0.84.3+） | 运行时 compaction 已关；若仍出现必须 fail-closed | 列入 `POLICY_VIOLATION_EVENT_TYPES` |
| `powershell` 内置工具（0.84.3+） | 新 shell 面 | 与 bash 同：需 `allowBash` + coding grant + isolated workspace |
| `before_agent_start` 的 `systemPrompt` 改为 leading system prompt（不再后贴） | prompt-mode 已是 `PI-DEFAULT + overlay` 整段替换 | 行为仍成立；未改 overlay 拼法 |
| `pi.on()` 返回 unsubscribe；`ModelRegistry.refresh` / headers `null` 等 0.84 签名 | 我们忽略 unsubscribe；`getApiKeyAndHeaders` 只看 `ok` | 无改动 |
